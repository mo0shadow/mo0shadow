## 🚀 Featured Projects

### 🛍️ Burando — Multi-Vendor Local Brands E-Commerce App
> A next-generation marketplace bridging independent local fashion brands and modern digital shoppers. **Flutter / .NET 9**

- 🛒 **Multi-vendor cart** — buy from several brands in one unified checkout
- 💳 **Paymob SDK** — secure card & wallet payments with cross-vendor payment splitting
- 📦 **Split-shipment tracking** — real-time order status with independent tracking IDs
- 🎯 **Product variants** — size/color/stock selection, with reviews tied to verified purchases
- 🤖 **AI recommendations & chatbot** — via a .NET API gateway to a Python FastAPI service
- 🧱 **Clean Architecture + BLoC**, with heavy response caching for fast catalog navigation

`Flutter` `Dart` `BLoC` `Clean Architecture` `Paymob` `REST API`
